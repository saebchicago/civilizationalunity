# Learning architecture

This site serves two goals at once: establish Abdullah al-Ahsan's scholarly record and help readers learn from it. The learning layer should remain source-grounded and should never blur Professor al-Ahsan's authored claims with editorial teaching aids.

## Primary learner journeys

1. **Start in 15 minutes** — read the four recurring categories (governance, dignity, cooperation, flourishing) and the publications under each.
2. **Study a theme** — follow one question through selected works using the Writing search.
3. **Use in a seminar** — compare works, carry open questions into discussion, and copy verified citation records.

## Learning principles

- Start with questions rather than jargon.
- Give readers a visible next step at every depth.
- Keep authored scholarship, editorial synthesis, and study prompts explicitly distinct.
- Show the record rather than describing it: a category, a claim or a role earns its place on the page by carrying a title, venue, year or date the reader can check.
- Ship content in HTML. Sections must not be injected by JavaScript after load: the served page is the page.
- Prefer primary/publisher/repository records over unsourced summaries.
- Preserve chronology so readers can see intellectual development rather than a flattened set of ideas.
- Make the Writing archive searchable by topic as well as filterable by publication type.
- Keep advanced research utilities available without forcing beginners to use them.

## Route model

`/explore` remains the canonical learning hub for backwards compatibility and search stability. `/learn` should redirect to `/explore`. Navigation may label the route **Learn** because that better describes the user task.

## The four categories

Professor al-Ahsan asked that the recurring line of argument be categorized as **Governance, Dignity, Cooperation and Flourishing**. That order is used site-wide. They are categories, not a causal sequence: no ordinals, no arrows, no forward/reverse mechanism. Each category on `/framework` and the homepage carries the works in which the argument is actually made.
